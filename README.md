# ⭐ لغز النجوم — Star Puzzle

لعبة ألغاز بلوك 2D (اسحب القطع واملأ الشبكة وامسح الصفوف والأعمدة)، مبنية على قاعدة مفتوحة المصدر مجربة بجودة عالية.

> **الترخيص:** GPL-3.0 — هذا المشروع مفتوح المصدر بالكامل ويمتثل لشروط الرخصة. تفاصيل حقوق الجهات المفتوحة المصدر: `LICENSE` و `docs/THIRD_PARTY_LICENSES.md`.

## 🎮 اللعب
1. اسحب قطع البلوك من الأسفل وضعها على شبكة 10×10
2. املأ صفاً أو عموداً كاملاً ليمسح ويمنحك نقاطاً
3. القطع لا تنتهي إلا إذا لم يعد يناسب أي شكل — خطط بذكاء!
4. سلسلة المسح المتتالية تمنح مكافآت مضاعفة

## 🛠️ البناء
```bash
./gradlew :android:assembleRelease :android:bundleRelease
```
يتطلب JDK 8 و Android SDK (build-tools 29.0.3).

الملفات الناتجة:
1. `android/build/outputs/apk/release/` — للتثبيت المباشر
2. `android/build/outputs/bundle/release/` — للنشر على Google Play
