# ⚓ سباق القراصنة — Pirate Dash v1.0-rc

لعبة جري لا نهائية (Endless Runner) بعالم قراصنة أصلي، مبنية من الصفر بـ HTML5 Canvas، مع غلاف أندرويد رسمي (Kotlin + WebView) وبناء APK/AAB تلقائي عبر GitHub Actions.

## 🎮 طريقة اللعب
| الحركة | لوحة المفاتيح | اللمس |
|---|---|---|
| تغيير المسار | ⬅️ ➡️ | سحب يمين/يسار |
| قفز | ⬆️ أو مسافة | سحب لأعلى / لمس |
| انزلاق | ⬇️ | سحب لأسفل |

## ✨ ميزات v1.0-rc
1. ثلاثة مسارات بقفز وانزلاق، سرعة متزايدة، ودورة نهار وليل (غروب، ليل بنجوم وهلال، فجر، نهار)
2. عملات ذهبية + جواهر 💎 (عملة نادرة تفتح الشخصيات وتشتري الإنعاش)
3. وجبات 🍖: كل 5 وجبات تفعّل *وضع الفجر* ( invincible + مغناطيس + ذهب مضاعف )
4. قوى خاصة: 🧲 مغناطيس، 🛡️ درع، ×2 ذهب مضاعف
5. طاقم من 6 شخصيات أصلية قابلة للفتح بالجواهر، منها شخصيتان محجبتان باحترام
6. إنعاش بعد الموت مقابل 5 💎 (مرة لكل رحلة)
7. مهام يومية مع مكافآت جواهر
8. أصوات مولّدة إجرائياً (WebAudio) بدون ملفات خارجية: عملة، قفز، ارتطام، شحمة البحر
9. عالم حي: جزر بنخيل، طيور، سحاب، موج متحرك، صناديق وبراميل جانبية
10. حفظ كامل محلياً: أعلى نتيجة، الرصيد، الجواهر، الشخصيات المفتوحة

## ✅ ميثاق الحلال (Halal Charter)
1. شخصيات أصلية 100% من تصميمنا — لا نسخ من أي أنمي أو عمل محمي (ون بيس أو غيره). الطاقم *مستوحى* من روح مغامرات القراصنة فقط.
2. لا صلبان، لا جماجم، لا سحر أو شرك — النجمة الثمانية الهندسية رمز اللعبة.
3. لا مشروبات محرمة، لا قمار — الانتعاش بجواهر تُكتسب باللعب فقط.
4. ملابس محتشمة للجميع، واللقيمر 🍖 وجبة حلال.
5. قيم إيجابية: التعاون، الشجاعة، الجهد.

> ملاحظة قانونية: استخدام أسماء أو تصاميم شخصيات ون بيس الفعلية يعرّض التطبيق للحذف من Google Play بسبب حقوق الملكية (Shueisha/Toei)، لذلك الطاقم أصلي بروح مشابهة.

## 🏗️ بناء APK / AAB
يتم تلقائياً عند كل دفعة للمستودع (GitHub Actions):
1. ارفع أي تعديل → تبني الأكشن تلقائياً
2. حمّل الملفات من تبويب Actions > آخر تشغيل > Artifacts
3. `PirateDash-APK` للتثبيت المباشر على الهاتف
4. `PirateDash-AAB` للرفع على Google Play

ملاحظة أمان: مفتاح التوقيع داخل المستودع حالياً (مقبول للتجربة). قبل النشر الرسمي انقله إلى GitHub Secrets أو مكان خاص.

## 🛠️ تشغيل الويب
افتح `index.html` أو جرّب GitHub Pages.
