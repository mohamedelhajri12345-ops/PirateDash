# 🏴‍☠️ سباق القراصنة — Pirate Dash

لعبة جري لا نهائية (Endless Runner) بروح عالم القراصنة، مبنية من الصفر بـ HTML5 Canvas.
تجري على سطح سفينة خشبية فوق البحر، تجمع الذهب، وتتفادى الصناديق والبراميل واللافتات.

## 🎮 طريقة اللعب
| الحركة | لوحة المفاتيح | اللمس |
|---|---|---|
| تغيير المسار | ⬅️ ➡️ | سحب يمين/يسار |
| قفز | ⬆️ أو مسافة | سحب لأعلى / لمس |
| انزلاق | ⬇️ | سحب لأسفل |

## ✅ ميثاق الحلال (Halal Charter)
1. شخصيات أصلية 100% من تصميمنا، ليست منسوخة من أي أنمي أو عمل محمي.
2. لا مشروبات محرمة، لا قمار، لا سحر أو شرك.
3. ملابس محتشمة، لا رموز مخلة أو مخيفة (النجمة بدل الجمجمة).
4. قيم إيجابية: التعاون، الشجاعة، البحث عن الكنز بالجهد.

> ملاحظة قانونية: الشخصيات مستوحاة من *روح* عالم القراصنة عموماً، وليست نسخاً من "ون بيس" أو أي عمل محمي، حتى يكون النشر على Google Play آمناً من حقوق الملكية.

## 🛠️ التشغيل
افتح `index.html` في أي متصفح، أو من رابط GitHub Pages بعد تفعيله.

## 📁 الملفات
1. `index.html` — واجهة اللعبة (عربية RTL)
2. `style.css` — التنسيق
3. `game.js` — محرك اللعبة كاملاً (رسم، فيزياء، تصادم، توليد)
